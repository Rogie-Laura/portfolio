# Rogie Josue Laura — Portfolio

One-page portfolio based on resume layout. Built with **Next.js**, **TypeScript**, and **Tailwind CSS**.

## Quick Start

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000)

## Customize

Edit **`src/data/profile.ts`** to update your info.

- Profile photo: `public/profile.png`
- Resume download: `public/resume.docx`

## Deploy

Push to GitHub and deploy on [vercel.com](https://vercel.com) for a free live URL to put on your resume.

```bash
npm run build
```
